# 交叉引用与论文问答智能体实施计划

## 概要

- 删除整组自定义 PDF 缩放控件，保留浏览器 PDF 阅读器自带缩放功能。
- 恢复 LaTeX 交叉引用和参考文献，并为译文提供可靠跳转。
- 增加基于当前论文、引用可校验的问答智能体。
- 保留已有未提交改动，不处理无关的 `README 2.md`。

## 实现改动

### 交叉引用

- 在清理 LaTeX 前保护 `ref`、`eqref`、`autoref`、`cref` 和各类 `cite` 命令，并与公式 token 一同校验。
- 收集章节、公式、图、表和算法标签；解析 BibTeX，建立可显示、可跳转的引用元数据。
- 翻译后恢复“式 (3)”“图 2”“第 4 节”“[17]”等链接；无法定位时保留可见文字。
- 翻译 JSON 增加交叉引用、文献及段落原文数据，同时保持旧数据兼容。

### 论文问答智能体

- 使用本地 SQLite FTS5 索引原文、译文、章节、段落、页码、公式和引用，不引入 embedding。
- 翻译后自动更新索引，旧译文首次问答时惰性补建。
- 新增论文问答、历史、清空会话和索引状态接口，复用服务端 DeepSeek 配置。
- 模型回答必须使用后端分配的证据 ID；未知引用重试一次，仍失败则返回证据不足。
- 右侧增加可收起聊天抽屉，并支持从段落提问及点击引用跳转。

### 网络与缓存

- PDF、LaTeX、译文和问答索引复用本地缓存，命中时不重复下载。
- 下载采用超时、有限重试和临时文件原子替换，支持失败后续跑。
- 新论文验收使用未缓存的 arXiv `2006.11239`。
