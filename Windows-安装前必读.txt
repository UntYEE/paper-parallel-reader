Paper Parallel Reader - Windows 安装前必读
=========================================

为什么会被拦截？

Windows 会给从互联网下载的 ZIP 添加“网络来源”标记。解压时，这个标记可能继续附加到
启动-Windows.bat 和 启动.ps1，导致智能应用控制阻止运行。这不代表程序已经检测出病毒。

推荐安装步骤

1. 确认 ZIP 来自：
   https://github.com/UntYEE/paper-parallel-reader/releases
2. 在文件资源管理器中右键点击下载的 ZIP，选择“属性”。
3. 在“常规”页面底部勾选“解除锁定”，点击“应用”，再点击“确定”。
4. 解压已经解除锁定的 ZIP。
5. 双击“启动-Windows.bat”。

如果已经解压后才发现被拦截

1. 删除刚才解压出的文件夹。
2. 对原始 ZIP 执行“属性 -> 解除锁定 -> 应用”。
3. 重新解压并启动。

高级处理方法

确认文件来源和 SHA-256 无误后，可以在解压目录空白处右键选择“在终端中打开”，运行：

Get-ChildItem -Recurse | Unblock-File

然后运行：

.\启动.ps1

安全提示

- 只对来自本项目 GitHub Release、且校验值一致的安装包解除锁定。
- 不要关闭 Windows 智能应用控制或 Microsoft Defender。
- 如果没有“解除锁定”选项，电脑可能受学校或公司的安全策略管理。请改用 README 中
  的 Docker 命令启动，或联系电脑管理员。
